# J.A.R.V.I.S. GPS TRACKER

Real-time GPS tracking tool with JARVIS HUD aesthetic.

## Live Demo
https://freedom00000000.github.io/jarvis-gps-tracker/

## Features
- Real-time GPS position tracking (browser Geolocation API)
- Animated pulsing position marker with accuracy circle
- Movement trail with distance counter
- Speed, altitude, heading, accuracy telemetry
- Compass heading display
- Share coordinates to clipboard
- Export trail as GPX file
- Trail persistence via localStorage
- Dark/Standard map toggle
- JARVIS HUD aesthetic with Iron Man theme
- Mobile responsive

## Usage
1. Open the page in a browser
2. Click **START TRACKING**
3. Allow location permission when prompted
4. Watch your position update in real-time
